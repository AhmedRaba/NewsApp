# 📰 News App

An Android News application developed using **Kotlin**, **MVVM**, **XML layouts**, and **Clean Multi-Module Architecture**. Built for the Silverkey Technologies Android task.

---

## 📱 Features

- Splash Screen with logo animation  
- Home Screen: News listing with:
  - Image, title, description, date
  - Favorite button toggle
  - Pull-to-refresh  
- Shimmer loading effect  
- Details Screen: Full article with image, author, content, and save/share actions  
- Favorite Screen: Only saved articles  
- Profile Screen: Static user info and logout button

---

## 🧰 Tech Stack

- **Kotlin**
- **MVVM** with **ViewModel** & **LiveData**
- **Retrofit** for networking
- **Room** for local database
- **Dagger Hilt** for Dependency Injection
- **Coil** for image loading (with placeholders & caching)
- **Shimmer** for loading effect
- **Multi-module Clean Architecture**
- **XML layouts**
- **Dark Mode Support**

---

## 🗂 Project Structure (High-level)

- **app**: UI Layer (Fragments, ViewModels, Adapters)  
- **domain**: UseCases, Entities, and Interfaces  
- **data**: Repository implementation, Room DAO, Retrofit API
